# Material de prueba para el demo

| Archivo | Para qué sirve |
|---|---|
| `sistema-solar.pdf` | Subir en Studio: propone el Lab 3D Sistema Solar |
| `mundo-de-las-fracciones.pdf` | Subir en Studio: crea la unidad de Fracciones |
| `hoja-cuaderno-1.jpg` a `-3.jpg` | Subir en el escáner de foto del cuaderno |

Las tres hojas muestran el mismo ejercicio con el error intencional en la línea 2: `1/3 + 1/4 = 2/7`.
El análisis es simulado y siempre devuelve el resultado de ese ejercicio, así que **otro ejercicio mostraría un feedback que no coincide con la hoja**.

Las hojas son imágenes generadas con letra manuscrita. Para el demo en vivo conviene escribir ese mismo ejercicio a mano en papel.
